# Perbaikan Player
24 frame PNG telah diperbaiki dengan menutup lubang transparansi kecil pada siluet karakter. Karena sumbernya JPG dengan latar hitam, beberapa detail tidak dapat dipulihkan sempurna. File game.json dan aset lain dipertahankan.

Cara pakai: ekstrak ZIP ini ke folder baru, buka game.json dari folder tersebut di GDevelop, jalankan Preview. Jika masih melihat gambar lama, tutup Preview dan buka ulang proyek dari folder baru.

Alternatif kualitas terbaik: gunakan spritesheet asli PNG transparan, bukan gambar poster JPG.
