# Pixel Team Adventure - GDevelop 5 Desktop

1. Ekstrak ZIP sampai terlihat `game.json` dan folder `assets` dalam folder yang sama.
2. Buka GDevelop 5 Desktop > File > Open > pilih `game.json`.
3. Klik Preview. Tombol panah kiri/kanan atau A/D untuk jalan; Space/Up untuk lompat; R untuk reset; Enter untuk ulang setelah menang.
4. Ambil 3 bintang untuk melihat peran, lalu menuju pintu. Hindari rintangan merah.
5. Edit logika melalui tab Events: satu JavaScript event agar mudah dipelajari dan disesuaikan.

**Penting:** JSON ini dibuat berdasarkan skema contoh proyek GDevelop, tetapi belum diuji langsung di aplikasi GDevelop Desktop. Jika muncul peringatan saat membuka atau preview, kirim screenshot agar dapat disesuaikan dengan versi aplikasi. Frame gambar berasal dari spritesheet yang disediakan, dan mungkin memiliki artefak hitam.

Tugas dosen meminta kolaborasi nyata; proyek individu memerlukan izin dosen. Jangan mengklaim kolaborasi fiktif.
